# Суть проекта
Проект представляет из себя хранение данных об операциях в Сбере
Эти данные собираюсь использовать в Firefly III в качестве личной бухгалтерии.
Сбер не дает физикам доступ к Сбре-API поэтому обрабатываются минимальные данные (к сожалению) которые можно выгрузить в блоке "Операции"

# Установка
Достаточно скопировать репозиторий, поднять docker-compose-yml и выполнить скрипты из директории sql (пока вручную)
Также пока-что стоит вручную создать директории:
```
data/
  └──archive/origin
  └──raw/origin

```
Сбер предоставляет 2 вида выгрузки операций, зачисления и списания, эти два файла необходимо положить в data/raw/origin и запустить проект
